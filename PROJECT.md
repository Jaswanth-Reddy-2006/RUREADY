# Project: RU Ready AI Interview Platform Overhaul

## Architecture
Monorepo using `pnpm` workspaces:
- `client`: React 18.3, Vite 6, Tailwind CSS 3.4, React Router DOM 6.28, Zustand 5, TanStack Query 5.
- `server`: Node.js 18+, Express 4.21, TypeScript 5.7, Prisma 6.2, PostgreSQL with `pgvector`.
- `packages/shared`: Shared DTOs, Enums, and TypeScript contract interfaces (`@ru-ready/shared`).

Dual Track Architecture:
- **Implementation Track**: Modular milestones (M1–M5) leading to final verification (M6).
- **E2E Testing Track**: Independent opaque-box testing track creating comprehensive multi-tier tests (Tiers 1–4) publishing `TEST_READY.md`.

## Interface Contracts

### 1. Design System Tokens (Client)
- Fonts: `font-display: ['Montserrat', 'sans-serif']`, `font-body: ['Outfit', 'sans-serif']`, `font-mono: ['JetBrains Mono', 'monospace']`.
- Obsidian Backgrounds: `bg-obsidian-950` (`#0A0B0E`), `bg-obsidian-900` (`#111318`), `bg-obsidian-800` (`#181B22`), `bg-obsidian-card` (`rgba(17, 19, 24, 0.7)` with `backdrop-blur-md`).
- Solar-Orange Accents: `text-solar-orange-500` (`#FF7A00`), `bg-solar-orange-500`, `hover:bg-solar-orange-600` (`#E66E00`), `ring-solar-orange-500/50`.
- Borders: `border-obsidian-border` (`rgba(255, 255, 255, 0.08)`), `border-solar-orange-500/30`.

### 2. Interviewer Persona Interface
- Enum / String types: `'HIRING_MANAGER' | 'TECHNICAL_ARCHITECT' | 'BAR_RAISER'`.
- Client payload: Passed in `createSessionSchema` via `interviewGoal` as `[Persona: HIRING_MANAGER]` or `[Persona: TECHNICAL_ARCHITECT]` or `[Persona: BAR_RAISER]` (safely backward-compatible with backend DB schema).
- Prompt adaptation: `ai.service.ts` parses persona tag and sets specialized interrogation persona and rubric focus.

### 3. Real-Time Telemetry Interface
- Audio Analyser: `AudioContext` + `AnalyserNode` (fftSize: 64, smoothingTimeConstant: 0.8), returning 32-bin frequency array. Visualizer maps to 16–24 dynamic height bars updated on `requestAnimationFrame` (sub-300ms response).
- Vocal Pacing: Real-time word count / elapsed minutes calculation (`wordsPerMinute = (wordCount / (elapsedSeconds / 60))`), displaying dynamic indicator: Slow (<110), Optimal (110–160), Fast (>160 WPM).
- Latency Gauge: Difference between user speech silence / submission timestamp and AI response initiation timestamp (in ms).

### 4. STAR Scoring & Radar Interface
- STAR Breakdown: `{ situation: number, task: number, action: number, measurableImpact: number, feedback: { situationText: string, taskText: string, actionText: string, impactText: string } }` (extracted from question evaluations).
- Competency Radar Dimensions: Communication, Technical Accuracy, Problem Solving / Structure, Confidence / Delivery, STAR Specificity (normalized 0–100 scale rendered via native SVG polygon).

## Code Layout
- `client/index.html`: Font links and root mount.
- `client/tailwind.config.ts`: Obsidian & solar-orange semantic design tokens.
- `client/src/index.css`: Global styles, obsidian dark base, glassmorphism utilities, scrollbars.
- `client/src/components/ui/`: UI primitives (`Button.tsx`, `Card.tsx`, `Input.tsx`, `Badge.tsx`, `Skeleton.tsx`, `RadarChart.tsx`, `ErrorBoundary.tsx`).
- `client/src/layouts/AppLayout.tsx`: App layout shell, navigation header, sidebar.
- `client/src/pages/`:
  - `Landing.tsx`: Landing page.
  - `Login.tsx`, `Register.tsx`: Authentication pages.
  - `Settings.tsx`: User preferences and settings.
  - `interview/SetupForm.tsx`: Standard interview setup with persona selector.
  - `interview/DeviceCheck.tsx`: Hardware & audio pre-flight validation.
  - `interview/InterviewRoom.tsx`: Oral interview orchestration room.
  - `interview/AnalysisReport.tsx`: Detailed interview evaluation.
  - `analysis/Dashboard.tsx`, `analysis/SessionDetail.tsx`: Historical metrics and past session reviews.
- `client/src/components/interview/`:
  - `NormalInterviewRoom.tsx`: Oral room presentation, live audio visualizer, latency gauge.
  - `CodingInterviewRoom.tsx`: Coding room with Monaco editor and test runner.
  - `CodingSetupForm.tsx`: Coding interview setup.
  - `AnalysisDashboard.tsx`: Comprehensive analytical report view with STAR breakdowns.
  - `AudioWaveformVisualizer.tsx`: Reusable real-time sub-300ms audio visualizer.
- `server/src/`:
  - `controllers/interview.controller.ts`: Session, answer, hint, run, telemetry endpoints.
  - `services/ai.service.ts`, `services/analysis.service.ts`: Evaluation, Socratic feedback, STAR compliance parsing.
  - `prompts/master_prompt.ts`: Personas, rubrics, and uninflated grading directives.
